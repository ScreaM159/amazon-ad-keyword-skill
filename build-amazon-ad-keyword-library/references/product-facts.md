# 产品事实核实（Step 0，必做）

## 为什么先做
关键词的"强相关"只对**特定材质/形态**成立。产品事实没核实，会把材质/形态不符的词当强相关投，导致低转化、高退货、浪费预算。
- 反例（本次真实发生）：把 `cast iron weight plates` 当强相关精准投；核实商品页后发现产品是 **rubber bumper plates（橡胶片+钢内芯）**，cast iron 材质不符，必须剔除/否定。
- 正例：`40 lb rubber bumper plates` 类词与 rubber bumper 产品形态、材质、受众一致 → 强相关。

## 核实清单（逐项确认，缺一项就标"待确认"）
| 项 | 确认方式 | 影响 |
|---|---|---|
| 材质 | 商品页 Material / bullet / A+ / 实物 | 决定材质词（rubber/cast iron/urethane/steel）取舍 |
| 类型/形态 | bumper / 传统片 / 六角 / 校准片 / 分片 | 决定类型词与形态陷阱词 |
| 规格 | 磅数、孔径(2inch/1inch)、是否英制/公制 | 决定规格词与"配置不符"否定 |
| 是否含杆/配件 | 套装是否含 barbell/rack | 决定 barbell(杆)/配件词归属 |
| 自有品牌 | 品牌名 | 品牌防御词 |
| 竞品 | 名称＋具体 ASIN＋评论/价格 | 竞品策略、ASIN 定投 |
| 目标市场/语言 | 站点 | 是否加西语等本地词 |

## 判定与记录
- **决策**：以核实结果为准，任何与词库标题/口语叫法冲突的，以产品事实覆盖。
- **例外**：多材质/多形态 SKU → 拆表分别处理，不混在一张词表。
- **输出记录**：写入"产品事实卡"并在最终表备注里标注材质/形态依据。
- **标记**：产品事实核实为 `[用户明确]`；本次 cast iron 误投案例为 `[已验证]`。

## 边界案例
- "rubber coated cast iron"：内芯铸铁、外覆橡胶——既沾 cast iron 又沾 rubber。若商品页写明，需在备注区分"面向 cast iron 搜索者"与"面向 rubber 搜索者"的意图差异；不确定时标 `[假设]`，小预算测试。
- 关键词含 "olympic"：指 2 英寸孔径标准，不等于材质；不能据此判断材质。
- **材质相符但搜索量低**（本次 urethane）：urethane 是本品实际材质之一，但相关词 ABA 排名靠后 → 不是"材质陷阱"，而是"材质相符、量低，标低优先/可不打"。判定要看 ABA，不要一律当材质不符。
- **相近写法是不同记录**：`25 lb weight plate`(ABA 251962) 与 `25lb weight plate`(402900) 在词库里是两条、ABA 不同；脚本/人工都不要空格归一混用，否则阈值判断会错。
