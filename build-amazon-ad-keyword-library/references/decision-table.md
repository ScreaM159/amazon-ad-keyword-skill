# 主决策表

格式：适用条件 / 证据 / 决策 / 例外 / 输出记录 / 标记。标记：`[用户明确]` `[已验证]` `[假设]`。

## D0 词库事实 vs 活动配置（1:N）
- 词库 = 关键词事实（一个词一条记录，保留原始写法/ABA/来源）。
- 活动 = 投放用途（一个词可有多条：不同阶段/匹配/活动/用途）。
- 决策："一词一记录"不等于"一词只能一种匹配"；执行视图可以一词多行，但每行须有明确用途/阶段/否定范围。
- 记录：活动行标注用途；词库行保留原始记录。
- 标记：`[用户明确]`（Codex 建议采纳）。

## D1 先核实产品材质与形态
- 适用：任意品类。
- 证据：商品页 Material/bullet、实物、用户确认。
- 决策：材质/形态不符的词剔除或否定。
- 例外：多材质/多形态 SKU 分表（见 D6）。
- 记录：产品事实卡 + 备注依据。
- 标记：`[用户明确]`。

## D2 词-品相关性
- 证据：形态/功能/受众；写理由。
- 决策：强/中/弱 + 理由（定性，不用"受众重叠>80%"这类无数据支撑的精确尺度）。
- 记录：相关性列 + 理由。
- 标记：`[用户明确]`。

## D3 精准阈值（运营指定；不预设）
- 证据：运营按产品设定的阈值；词库 ABA 周排名。
- 决策：ABA≤阈值→可精准；>→降级或剔除。**未给阈值时标"待确认"，不得用脚本默认值替用户下结论**。
- 例外：品牌防御词单列阈值（见下）；真实规格词（ABA 可接受 + 规格真实存在）可登记例外。
- **品牌防御**：自有品牌词单独规则/阈值，不因普通流量门槛被删。
- 记录：备注写"达标/超阈值/例外/品牌防御"。
- 标记：`[用户明确]`。

## D4 材质：硬性不符 / 相邻替代 / 待核实
- 证据：产品事实卡的实际材质。
- 决策：
  - **硬性不符**（如 rubber 品遇 cast iron）→ 否定；**不因阶段升级自动解禁**。
  - **相邻替代**（如 urethane 是本品实际材质、但相关词 ABA 靠后）→ 不否定，标"材质相符但量低，低优先/可不大"。
  - **待核实**（材质不明/复合材质）→ 标待确认，不硬判。
- 复合材质（如 "cast iron"）：按最长匹配优先，不能把 cast iron 里的 iron 误判成另一种材料。
- 标记：`[用户明确]` + `[已验证]`。

## D5 形态/配件陷阱词
- 适用：rack/holder/tree/storage、dumbbell/kettlebell、barbell(杆)、vest/plate carrier/rucking、armor/bumper guard。
- 决策：弱相关/不相关→否定；若卖该配件另立。
- 标记：`[用户明确]`。

## D6 单 SKU vs 多 SKU（项目参数）
- 由运营定；默认单 SKU 一套表；差异大才分表。历史案例/具体产品不作为通用规则。
- 标记：`[用户明确]`（项目参数）。

## D7 竞品三种用途（分开定义）
- **品牌+品类 精准**：截流确切竞品词。
- **品牌+品类 词组**：覆盖品牌各变体。
- **ASIN 定投**：投竞品详情页（通常成熟期）。
- 决策：三种按用途选，不混；具体打哪些品牌由运营给（D16）。
- 标记：`[用户明确]`。

## D8 放量=精准
- 决策：对已验证词提价/加预算/抢位；广泛只做探索线。
- 标记：`[用户明确]`。

## D9 词组匹配：核心短语 + 必配否定
- 种子用**核心短语**（`weight plate`、`bumper plates`），不用带规格/材质变体（`35 lb weight plate`、`olympic bumper plates`）——短语覆盖前后加词。
- **必配词组否定异类**：`weight plate` 会命中 `weight plate rack/holder/tree/storage/carrier` → 词组否定；`bumper plates` 同理否 rack。
- **与精准隔离**：精准已投词在词组活动精准否定。
- **不同主题不合并**（weight plate vs bumper plates）。
- 标记：`[用户明确]`。

## D10 匹配组合 + 否定类型
- 判断先定：站点/商品/阶段/匹配/用途/否定范围；不同阶段的行不等于同时投放。
- 组合矩阵：
  - Exact+Exact：同范围无差异→合并。
  - Exact+Phrase：**允许**（Exact 承接已知需求，Phrase 扩长尾）；Phrase 活动精准否定已启用 Exact 词。
  - Exact+Broad：**允许**；Broad 活动精准否定已启用 Exact 词。
  - Phrase+Broad：**默认减少同主题重叠，但非平台技术禁止**；若并存须说明增量；可评估在 Broad 词组否定 Phrase 负责的短语（见否定类型）。
  - 三层齐全：不因"齐全"默认创建，也不一律禁止；无法解释增量则简化。
- **否定类型**：精准否定=否确切搜索词、把已知需求**转交**精准；词组否定=否含该短语的整段范围（挡异类/品类）；**不得在 Phrase 里词组否定自身种子**（会连坐废掉活动）；Broad 向 Phrase 转交可评估词组否定，但要确认剩余探索仍有效。
- 不把跨活动重叠写成"必然自抬竞价"；上线用搜索词报告核验。
- 标记：`[已验定]` + `[用户明确]`。

## D11 否定按活动
- 否定按活动/广告组生效、不跨活动；每活动各挂一份；Exact 一般不加。
- 初始否定分三类：硬性排除 / 待验证 / 阶段暂不投；"不投"≠全局否定。
- 运营二次维护。
- 标记：`[已验证]`。

## D14 数据口径
- 判定统一用 ABA 周排名；月搜索量仅参考；"月低周高"正常。
- 原始写法/单复数/词序的 ABA 不互换；归并保留映射。
- 多源：先对齐站点/周期/导出时间/指标类型；无法对齐保留冲突；min/max 只是启发式。
- 标记：`[用户明确]` + `[已验证]`。

## D20 搜索结果反向验证
- 偏泛/存疑词→亚马逊搜前5-7条：纯异类→否定、混合→降级、同类→保留；反爬则手动。

## D21 阶段编排（不判阶段）
- 可按用户指定的阶段框架编排，但**不判定产品当前处于哪阶段**，不假定已有高自然位/高转化。
- 前阶段每个主题在下一阶段标注：保留/转其他匹配/停止/待验证 + 理由。
- 缺广告数据时，"低价收割/提竞价/放预算"写成**条件建议**，不声称已高转化。
- 标记：`[用户明确]`。

## 代表性案例
- 正例：`45 lb plates` 配置强、ABA 3.7w → 精准。
- 反例：`cast iron weight plates` 对 rubber 品 → 材质硬性不符，否定。
- 反例：`weight plate holder/rack` → 形态=收纳架，弱相关，否定。
- 边界：`25 lb weight plate`（251,962）与 `25lb weight plate`（402,900）是两条，不混用。
- 边界：`cast iron` 商品不应把内部 `iron` 误判为另一种材质。
