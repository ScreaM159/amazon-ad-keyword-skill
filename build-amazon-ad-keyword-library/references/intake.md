# 调用前问询清单（intake）——必须先问后做

触发本 skill 后，不要直接开始做。先向用户逐项确认下列问题（可合并成一条消息问，附默认建议），全部确认后再进入 Step0。

## 必问项
1. **产品事实（用户提供）**：材质 / 形态类型 / 规格 / 是否含杆配件 / 是否可调 / 硬或软 / 自有品牌 / 是否卖套装。（上架前没有本产品页，必须由用户给；若用户给类目页，AI 读类目辅助校验，见 product-facts-auto.md）
2. **是否卖套装**？（决定 set/sets 词保留还是否定）
3. **ABA 阈值**：本次用多少？（运营按产品定；例：壶铃用 16w。**skill 不预设**）
4. **大词判定标准**：怎么算大词？（运营定；例：ABA≤X 或指定词。**skill 不预设**）
5. **竞品名单**：本次要打哪些品牌/ASIN？哪些"打得过"、哪些不投？（**由用户给，skill 不写死**）
6. **ASIN 定投**：做不做？放哪个阶段？（如仅成熟期）
7. **是否按阶段排版**：新品/成长/成熟，还是单一阶段？
8. **广泛/词组**：是否按词根汇总？（默认是，避免词太多；**不卡 ABA 阈值**）
9. **数据源**：卖家精灵导出 CSV / 爬取 / 已有词库？关键词、ABA、搜索量的列在哪？
10. **口径确认**：词库全集不删、广告活动只筛选——确认？

## 问法建议
- 一次问完，给出默认建议，让用户勾选/改。
- 用户明确说"按惯例/你定"的项，用建议值并在输出里标注"默认，可改"。
- 用户的答案写进「人工决策记录」，便于复盘。

## 确认后
进入 Step0（核实产品事实）→ 读词库 → 分类 → 出词库（全集）+ 广告活动（筛选，按 activity-template 结构）。
