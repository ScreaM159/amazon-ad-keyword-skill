# 生命周期投放 playbook（仅供参考，skill 不执行）

> 本 skill 只输出"词库+匹配方式+打法"，**不判定投放阶段、不做阶段切换**。本文件仅供运营在排期时参考，不是 skill 的决策步骤。
> 规则标记：打法框架 `[用户明确]`；词数公式 `[假设]`；阶段信号 `[假设]`。

三阶段核心变量始终是："链接能否承接" + "该流量的边际价值"。

## 新品期（评论<~15、BSR未进首页）
- 目标：养权重、攒转化数据、控 ACOS（不是冲销量）。
- 投：强相关＋长尾＋高意图（配置规格词、材质词、带属性长尾），Exact/Phrase 抢首页。
- 不投：大词（打不动）、竞品词（没评论）、中相关（不确定）。
- Auto：只开紧密，用于挖词。
- 否定：全量否定包，首日起挂。
- 预算：集中 20–30 个高意图词（按预算/CPC/5 校准）。
- 记录：哪些词有转化 → 作为成长期升级依据。

## 成长期（评论起来、自然单出现、BSR爬升）
- 目标：抢排名、放量，ACOS 适度放宽（广告单=买自然排名）。
- 放量方式：对已验证词**提竞价+加预算+抢位**（精准，不是广泛）。
- 新增：大词 Exact 抢位；竞品"品牌+品类"精准 或 ASIN 定投；中相关词小预算测。
- 宽匹配：Broad 挖词/扩量（小预算），词组只留 5-8 主题词根（或先不建，用 Broad 顶）。
- Auto：全匹配（紧密+宽泛+同类+关联）。
- 否定：持续补充；宽活动精准否定精准层词。
- 词数：50–100（按公式校）。

## 成熟期（核心词自然位稳、自然单占比高、BSR平台期）
- 目标：利润最大化＋份额防守。
- 精准分层：收割层（降竞价挤利润）／守位层（大词维持出价守首页）／品牌防御（自有品牌占位）。
- 宽匹配：中相关泛词 Broad 低价捡量（成熟期权重高，泛流量也能转）。
- 竞品：全量放开＋品牌防御。
- 新增：SD 再营销（浏览未购/加购未购）、SB 品牌（有备案）。
- KPI：分层目标 ACOS（守位词容忍高、收割词要求低、捡量词卡很低）。
- 风险：防守广告砍太狠→排名滑坡；收割降竞价一刀切→掉位螺旋（小步降）。

## 词数公式（`[假设]`）
`词数 ≈ 日预算 ÷ CPC ÷ 5`（每词日均≥5点击才有统计意义）。
例：$100 / $1 / 5 = 20 词；$500 / $1.2 / 5 ≈ 83 词。

## 阶段切换信号（`[假设]`）
评论量+评分（如>15-25、≥4.2）、稳定自然日单、已验证词可复现转化、BSR 持续爬升。未达不提前放量；提前需注明原因。
