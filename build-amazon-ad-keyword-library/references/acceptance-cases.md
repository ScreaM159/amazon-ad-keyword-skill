# 验收案例（最小回归清单）

上线/交付前逐条验证；任一条不通过则修规则或脚本，不只改提示词。

## 业务行为
| # | 场景 | 必须验证 |
|---|---|---|
| 1 | 同一主题 Exact＋Phrase | 两条合法配置都保留；Phrase 活动里对 Exact 已投词做**精准否定** |
| 2 | 只改变阶段 | 词库关键词与原始 ABA 不变；活动差异可追溯 |
| 3 | 前阶段有 Phrase、后阶段没有 | 有明确的转移／停止／待验证理由，不能只写"进入成熟期" |
| 4 | 精准词 ABA 缺失或超阈值 | 不静默进入常规精准；豁免需明确规则并记录 |
| 5 | `25 lb` 与 `25lb` 排名在阈值两侧 | 分别判断，不借用另一写法排名 |
| 6 | 低 ABA 规格词 | 保留"配置/规格"角色，不因流量大就自动从新品配置精准移除 |
| 7 | 正向词与否定包冲突 | 按实际阶段/商品/活动/否定类型检查；精准层隔离不误报为全局冲突 |
| 8 | 当前未投竞品／新候选品牌 | 不自动变成全局否定，也不自动扩大授权名单 |
| 9 | 材质事实与历史范例不同 | 当前产品事实优先，历史示例不覆盖事实卡 |
| 10 | 同一字段旧版与最终版冲突 | 以确认的最终版为准；无法消解处列出证据与影响 |

## 脚本行为
| 校验 | 期望 |
|---|---|
| 主要核心词但中相关 | 不判精准（先过相关性） |
| ABA 缺失 | 标"待补ABA"，不写"达标" |
| 纯品牌竞品词 | 输出"不投/转ASIN"，且备注一致 |
| 产品材质为 cast iron | 不把内部 `iron` 误判为另一种不符材质 |
| 表头列顺序不同 | 按列名/别名定位仍能读取，不因列号变化读错 |

## 否定类型
| 场景 | 期望 |
|---|---|
| Exact 已投词在 Broad/Phrase 活动中 | 用**精准否定**转交，不用词组否定 |
| 挡异类/品类（rack、dumbbell） | 用**词组否定** |
| Phrase 活动自身种子 | **不得**用词组否定自身种子（会连坐废掉活动） |
