# Step -1：类目页 + 用户产品事实 → 分析 + 竞品搜集（上架前）

## 背景（关键）
广告在 **listing 上架前** 准备，本产品页还不存在。因此**不要读"我的商品页"**，而是：
- 读 **类目代表商品页**（同类目热销/竞品链接）→ 了解品类特征、找竞品、辅助校验；
- **产品事实由用户直接提供**（下面 8 项），AI 不猜。

## A. 用户提供本产品事实（8 项，缺项就问）
1. 材质（cast iron / rubber / urethane / vinyl / steel / PVC / 软填充…）
2. 形态类型（kettlebell / dumbbell / weight plate / bumper / barbell…）
3. 规格（lb / kg / 尺寸）
4. 是否含杆/配件（barbell / rack / stand / handle）
5. 是否可调（adjustable）
6. 硬或软（hard / soft）
7. 自有品牌
8. 是否卖套装（set / pair / kit）
> 用户没给全 → 逐项问；不要硬猜。

## B. 读「类目代表商品页」（用户给 1 个链接；或 AI 搜类目热销取前几个）
1. WebFetch 优先，失败/反爬用 browser-use。
2. 抓：标题、bullet、Material、变体（尺寸/重量）、价格、评分、评论数、品牌。
3. 用途：
   - 了解该品类**常见材质/规格/形态**（如壶铃常见 cast iron / powder coated / soft）。
   - **校验用户给的 8 项是否与类目一致**：不一致就追问（如用户说 cast iron，但类目主流是 soft → 请确认）。
   - 作为竞品/关键词来源。

## C. 自动搜集竞品（打哪些/不打哪些）
1. 从类目页/类目搜索结果（browser-use 搜核心品类词，前 1–2 页）抓：品牌、ASIN、价格、评分、评论数。
2. 筛"能打的"（规则可被运营覆盖）：
   - 打：中小牌、评论少、评分/价格不占优、配置材质与本品相同；
   - 不打：大牌/低价大牌、形态材质不符。
   - 评论门槛由运营定（给建议值并标注）。
3. 输出「竞品建议名单」：`品牌 | ASIN | 价格 | 评分/评论 | 建议(打/不打) | 理由`，交用户确认。

## D. 提问触发（务必先问再做）
- 用户 8 项有缺项 → 问；
- 用户事实与类目页明显矛盾 → 问；
- 品类有多种形态/材质，无法确定本品属于哪种 → 问；
- 竞品"能不能打"存疑 → 给建议 + 让用户拍板。

## E. 产出 & 后续
- 产品事实卡（用户提供 + 类目校验结果 + 待确认项）。
- 竞品建议名单（待确认）。
- 确认后进入 intake 其余项（ABA 阈值 / 大词 / 阶段 / 数据源）→ Step0。

## 风险
- 亚马逊反爬/验证码：抓不到就请用户发类目页截图或口述品类特征。
- 类目页只是"品类参考"，**不能替代本产品事实**——本品事实永远以用户为准。
