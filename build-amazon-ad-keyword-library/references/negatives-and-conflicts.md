# 否定词与冲突处理

> **单一规则源**：否定类型（精准/词组）与匹配组合规则以 `decision-table.md` 的 **D10** 为准；本文只列"否定来源 / 作用域 / 维护"。

## 否定来源（每类都要有归属活动）
1. **词库"否定候选"**：分层=否定候选 / 相关性=弱相关或不相关的词。
2. **材质陷阱**：产品材质不符的材质词（如 rubber 品的 cast iron/iron/steel/urethane，若没有该材质款）。
3. **形态陷阱**：rack/holder/tree/storage、dumbbell/kettlebell、barbell(杆)、vest/plate carrier/rucking、armor/bumper guard（汽车/防弹）。
4. **配置不符**：不售的磅数/孔径（如只卖 2inch 则否 1inch；不卖 5lb/100lb 则否）。
5. **搜索词报告补充**：每周从 ST 报告把跑量不相关词补入。
6. **品牌哑铃/异类**：竞品品牌下的非本品词（如 cap rubber coated dumbbell）。

## 作用域与维护
- 按**活动/广告组**生效，**不跨活动**。
- 自动/广泛/词组活动**各挂一份**；Exact 一般不加。
- 隔离用**精准否定**；挡品类用**词组否定**（不可用词组否定做同根隔离，会连坐）。
- **本 skill 只输出"初始否定包"；后续由运营二次维护**（每周/按需从 ST 补充）。

## 冲突处理顺序
1. 完全同词多活动 → 去重。
2. 同根 Exact+Phrase/Broad → 宽活动精准否定精确词。
3. 同主题 Phrase+Broad → **默认减少重叠，非技术禁止**（以 D10 为准）；按能否解释增量判断，必要时评估在 Broad 词组否定 Phrase 负责短语、把范围交给 Phrase。
4. 一活动一匹配方式，避免同活动混投。

## 记录要求
否定包要写清：否定词、类型（精准/词组）、归属活动、理由。人工删/改需记入"人工决策记录"（日期/谁/理由/影响），可查回。
