# 广告活动最终版结构模板

输出"广告活动"时严格用此结构：**三阶段 + 分区块 + 逐词 + 4 列**。
列：`关键词 | 匹配方式 | 关键词类型 | 备注`

## 关键约定
- **词库全集不删**；本表只放**过滤后**的词（如精准 ABA≤阈值）。
- 一个词只出现在它该在的区块；同根词跨活动时用精准否定隔离。
- 竞品词：品牌+品类、词组匹配；大牌剔除；ASIN 定投只在成熟期。
- 逐词一行，不聚合；备注可写 ABA/理由。
