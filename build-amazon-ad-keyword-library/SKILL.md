# 亚马逊广告关键词词库搭建

**版本：0.1beta** ｜ 变更记录见 `references/changelog.md`

## 职责边界（重要）
本 skill 只输出三样：**① 关键词词库（全集，不删）　② 每个词的匹配方式/归属活动　③ 打法说明**。
**不判定**投放阶段、阶段切换、预算配比——运营的事；但**可按用户指定的阶段框架编排**，不替用户判断当前处于哪阶段、不假定已有高自然位/高转化（缺数据时"收割/提竞价"写条件建议，见 D21）。

两条硬规则（实操验证）：
- **词库是全集、不删**；"广告活动"只做**筛选**（如精准词按 ABA 周排名阈值），不要为了精简而删词库。
- "广告活动"严格按 `references/activity-template.md` 的最终版结构输出（新品/成长/成熟 + 分区块 + 逐词 + 4列）。

## 调用流程：先问后做（必须）
**广告在上架前准备，本产品页还不存在**：产品事实由**用户直接提供**（材质/形态/规格/杆配件/可调/软硬/品牌/是否套装）；若用户给**类目商品页链接**，则读它"了解品类 + 自动搜竞品"（见 `references/product-facts-auto.md`），并校验用户事实与类目是否矛盾。**缺项/矛盾/形态不清晰 → 先向用户提问**，确认后再走 intake 其余项。
否则，直接按 `references/intake.md` 向用户逐项确认，再动手；不要自己假设阈值、竞品名单、大词标准。确认清单至少包含：
1. 产品事实：材质 / 形态类型 / 规格 / 是否含杆配件 / 是否可调 / 软硬 / 自有品牌。
2. 是否卖套装（决定 set/sets 词保留）。
3. **ABA 阈值**：本次用多少？运营按产品定，skill 不预设（如某项目用 16w，仅为示例）。
4. **大词判定标准**：运营定（如 ABA≤X），skill 不预设。
5. **竞品名单**：本次要打哪些品牌/ASIN、哪些"打得过"、哪些不投——**由用户给，skill 不写死品牌名单**。
6. ASIN 定投做不做、放哪个阶段。
7. 是否按阶段（新品/成长/成熟）排版。
8. 广泛/词组是否按词根汇总（默认是，避免词太多；**不卡 ABA 阈值**）。
9. 数据源（卖家精灵导出 / 爬取 / 已有词库）。
10. 口径确认：**词库全集不删、活动只筛选**。
确认完成后，再进入 Step0。

## 规则标记（全文通用）
- `[用户明确]` 用户明确要求，直接执行。
- `[已验证]` 经数据/商品页/实操确认。
- `[假设]` 经验值/待验证，使用前确认，不得当固定标准。

## 一、输入要求
1. 词库表：关键词、翻译、来源备注、周搜索量、ABA周排名、分层、相关性。
2. **产品事实卡**：材质、类型/形态、规格、是否含杆/配件、自有品牌、竞品（名称＋ASIN）。
3. **ABA 阈值**：由运营按产品自定义（不是固定值）；**未提供时标"待确认"，不得用脚本默认值替用户下结论**。
可选：现有活动结构（对齐命名/隔离）。

## 二、工作流
0. **核实产品事实**（必做，见 `references/product-facts.md`）。材质/形态错，全表错。
1. 读词库并校验：`scripts/read_wordlib.py`。
2. 复核分层与相关性：`references/decision-table.md`。对偏泛/存疑词用**亚马逊搜索结果反向验证（D20）**：纯异类→否定、混合→降级、同类→保留。
3. 分配匹配方式：`scripts/classify_keywords.py`（参数：xlsx、sheet、ABA阈值、产品材质）。**判定统一用 ABA 周排名；月搜索量只作参考（非同一口径，出现"月量低但周排名高"属正常）**。输出匹配方式+归属活动+打法备注，并做材质/重复/冲突校验。
4. 否定与隔离：`references/negatives-and-conflicts.md`。
5. 活动架构：一活动一匹配，命名可检索，否定标注归属活动。
6. 输出「人工决策记录」页。
7. 按验收清单交付。

## 三、输出字段（固定）
`关键词 | 匹配方式 | 关键词类型 | ABA周排名 | 归属活动 | 打法备注`
- 匹配方式：精准匹配/词组匹配/广泛匹配/否定/商品定位(ASIN定投)/剔除。
- **词库=一词一记录（保留原始写法/ABA/来源）；活动=一词可多行**（不同阶段/匹配/用途），即 1:N（见 D0）。
- **不输出"投放阶段"列**（阶段由运营决定）。
- 打法备注可溯源（ABA 达标/超阈值/材质不符/材质相符但量低/同根隔离/竞品意图杂等）。

## 四、验收标准
- [ ] 精准词满足**运营设定的 ABA 阈值**，超阈值的要么降级、要么作为"真实规格词"登记例外（判据：ABA ＋ 该规格是否真实存在）。
- [ ] **ABA 缺失不判"达标"**，标"待补数据"。
- [ ] 匹配组合符合 D10（Exact+Phrase 允许并精准否定；Phrase+Broad 非技术禁止但需说明增量）。
- [ ] 无同根多方式自抢（同文本/近似写法/主题词组/泛语义分层判断）。
- [ ] 材质/形态不符词已剔除并加否定；材质相符但 ABA 靠后的词标"低优先/可不大"。
- [ ] 竞品词按 D7 三种用途（品牌+品类精准 / 品牌+品类词组 / ASIN），纯品牌未硬投。
- [ ] 品牌防御词单列阈值例外，不因普通流量门槛被删。
- [ ] 原始写法/单复数/词序的 ABA 不互换。
- [ ] 否定按活动各挂（初始包），并注明由运营二次维护。
- [ ] 每词可溯源；已生成「人工决策记录」页。

## 五、缺失/冲突/低置信度处理
- 缺 ABA：标"待补数据"，不判阈值。
- 字段冲突（词库 vs 产品事实）：以产品事实为准，记入人工决策记录。
- ABA 临界 / 意图歧义：标"待验证"，不写死。
- `~$` 锁文件：提示关闭 WPS。
- 含 DISPIMG 图片/透视表：禁用 openpyxl 保存，用 `scripts/write_sheet_safe.py`。
- **相近写法要分清**：`25lb weight plate` 与 `25 lb weight plate` 是两条记录、ABA 不同，不得空格归一混用。
